## Description

An Android application that allows users to explore information about China's four municipalities: Beijing, Shanghai, Tianjin, and Chongqing. Users enter a municipality name, the app validates the input, and displays customized information with matching colors and images.

## Features

- Input validation (case-insensitive, rejects unknown cities)
- Two-screen navigation using explicit intents
- Dynamic UI styling based on selected municipality
- Implicit intent to open official municipal websites
- Scrollable information section

## Screens

1. **Main Activity** - Title, map image, and text input field
2. **Municipality Activity** - Municipality name, image, description, and "Visit site" button
